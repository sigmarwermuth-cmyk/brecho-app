# 👕 Brechó App

Um aplicativo profissional de compra e venda de roupas e objetos usados.

## 🚀 Funcionalidades Planejadas

### Nível 1: Essencial
- [ ] Catálogo de Produtos (Foto, Preço, Tamanho, Estado)
- [ ] Filtros de Busca (Categoria, Tamanho, Preço)
- [ ] Cadastro de Produtos
- [ ] Autenticação de Usuários

### Nível 2: Interação
- [ ] Carrinho de Compras
- [ ] Perfil do Usuário (Meus Produtos / Minhas Compras)
- [ ] Chat de Interesse

### Nível 3: Profissional
- [ ] Painel de Administração (Moderação)
- [ ] Gestão de Status do Produto (Disponível/Vendido)
- [ ] Sistema de Avaliações

## 🛠️ Stack Tecnológica
- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Node.js + Express + TypeScript
- **Banco de Dados:** MySQL
- **Imagens:** Cloudinary

## 📁 Estrutura do Projeto
- `/client` - Frontend React
- `/server` - Backend Node.js
